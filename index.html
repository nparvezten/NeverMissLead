NeverMissLead Standalone Widget Demo

This page demonstrates embedding the NeverMissLead chat widget into any external website with a single custom HTML element.

Embed Code Example:

<!-- Include Widget Script --> <script src="http://localhost:4200/main.js" type="module"></script> <!-- Drop in the Custom Web Component --> <nml-chat-widget businessId="a1b2c3d4-e5f6-7890-abcd-ef1234567890" apiBaseUrl="http://localhost:5103" brandColor="#4f46e5" greeting="Hi! How can I help you today?"> </nml-chat-widget>

Click the floating launcher button on the bottom right to start a grounded RAG chat session!
